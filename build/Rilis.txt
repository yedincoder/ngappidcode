# Changelog - NgAppID Code Editor 1.0.1

### 🌟 Fitur & Peningkatan Utama
* **Global Search in Files**: Fitur pencarian teks global di seluruh direktori project secara instan untuk memudahkan pelacakan baris kode.
* **Full Light & Dark Mode**: Integrasi tema terang (*Light*) dan gelap (*Dark*) secara menyeluruh yang mencakup area editor Monaco, *sidebar*, terminal, hingga halaman *Welcome Screen*.
* **Inline File & Folder Creation**: Pembuatan file atau folder baru langsung di dalam *sidebar* secara *inline* tanpa perlu dialog *prompt* pop-up.
* **Settings Sub-Menu Dropdown**: Pengaturan editor dikemas rapi dalam menu *dropdown* terstruktur di *topbar* untuk navigasi tema dan ukuran font.
* **Terminal Donasi & QRIS**: Tambahan perintah terminal `donasi`, `support`, atau `traktir` yang menampilkan QRIS berdampingan dengan informasi saluran dukungan.
* **Auto-Close & Toggle Dropdown**: Perbaikan perilaku menu *dropdown* (Git & Settings) agar saling menutup otomatis dan responsif di halaman *Welcome Screen*.
* **Cross-Platform Path Resolver**: Penanganan pemisah direktori path (`/` dan `\`) yang lebih aman dan kompatibel di berbagai OS (Windows, Linux, macOS).
